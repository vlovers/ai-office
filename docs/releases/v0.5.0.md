## Highlights

- Directory-grouped file navigation and bounded unified Git diffs.
- General, file, and line feedback, saved in SQLite and bound to a specific revision.
- Explicit **Request Changes** confirmation resumes the original Codex session through the existing queue and worker. No replacement thread or automatic merge.
- Preserved review iterations and manually controlled **Keep** / **Reject** actions.
- Fail-closed safeguards against stale revisions, duplicate correction submissions and feedback loss after failed saves.

## Upgrade / start

Requires Node.js 24.x, a supported Codex CLI and a functioning local sandbox. No API key is required when an existing ChatGPT Codex CLI login is available.

```sh
npm ci
npm run build
npm start
```

Open http://127.0.0.1:4310.

## Safety and known limitations

Single-user local tool. The default mode is read-only; isolated writes require server-configured roots and explicit approval. Do not point it at production or confidential repos without reviewing security requirements. Historical patches are bounded and depend on native Codex transcripts. Linux native sandbox remains unverified; host verification is disabled by default and requires opt-in with broad host privileges. Kept changes require manual integration; no background deployments, automatic merge or inference was performed as part of the release evidence.
