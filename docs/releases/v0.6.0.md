# AI Office v0.6.0 — Agent Studio (published)

> [v0.6.0 was published on 2026-10-18](https://github.com/vlovers/ai-office/releases/tag/v0.6.0), from tag commit `03bfa73a`. The checklist below preserves pre-release verification requirements; unchecked items are **not** retroactively claimed complete.

## Highlights

- Persistent, versioned Codex agent profiles with Studio create/edit/duplicate/archive/restore workflows.
- Immutable submission, execution and session configuration snapshots; resumed and corrected tasks reuse their original native Codex session/policy.
- Bounded fair scheduler and conservative capacity quarantine where worker cleanup cannot be confirmed.
- Transactional schema-7/schema-8 migrations from the released v0.5 schema-6 baseline, preserving review history and queue ownership.
- Accessible Agent Studio UI, browser regressions and preserved v0.5 Code Review Center.

## Known limitations

AI Office remains a local-first single-user tool, not a hosted service or secret vault. Profiles and instructions are plaintext metadata; validators catch only known/configured secret patterns, not all secrets. API provider model IDs are syntax-validated, not proven available. Existing native Codex transcripts are required for resume. Sandbox checks were macOS-specific, not Linux validation; real inference was not performed for v0.6.

## Suggested release description

Agent Studio brings persistent, customizable Codex profiles, immutable execution settings, fair bounded scheduling, and an accessible Studio UI to AI Office. Existing v0.5 review/correction workflows are preserved. See the validation report and known limitations above before upgrading. This release does not claim general-purpose runtime isolation or Linux sandbox validation.
